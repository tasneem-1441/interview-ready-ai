# Interview Ready

"Build a mobile-first responsive web application called 'NCS InterviewReady AI'. The tool is a multi-step preparation environment

designed for job seekers. It must feature a dark-slate/indigo clean tech aesthetic using TailwindCSS and Lucide icons. Create a

single-page reactive dashboard state that orchestrates 5 main steps sequentially: 1. TARGET JOB SELECTOR: A drop-down

menu with mock NCS vacancies alongside a custom text area to paste any external Job Description. 2. RESUME FIT ENGINE: A

drag-and-drop file upload zone that mock-parses a user's resume PDF. It must output a clear visual contrast showing matched

corporate skills alongside glaring technical or soft skill gaps. 3. INTERVIEW SIMULATOR: An elegant audio/text terminal interface

that simulates a live role-specific interview. It must render a progress indicator tracking 3 question classes: Technical, HR, and

Behavioral. It must include a functional toggle between Text responses and simulated Audio Record responses. 4. METRIC

ASSESSMENT REPORT: A deep visual score screen displaying an explicit mathematical 'Readiness Score' calculated

dynamically via a weighted average formula: 35% Resume-Job Fit, 30% Interview Answer Quality, 20% Voice/Delivery Metrics

(such as pace, filler words, and long pauses), and 15% Soft Skills. Include clear sub-category progress bars with reasons. 5.

RE-TEST PRACTICE PLAN: A view that renders 2-3 specific, actionable training tasks targeting the user's lowest-scoring

sub-metric alongside a prominent 'Retest Now' button to cycle back into the application flow."

This project was built with [Lovable](https://lovable.dev).
